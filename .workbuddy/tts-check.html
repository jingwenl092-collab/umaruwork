④ 如果还是没声音，按这个顺序排查

  1. 刷新页面（Ctrl + F5）。Chrome 的语音引擎经常会被卡住，刷新是最有效的一招。
  2. 看系统音量和输出设备：右下角喇叭 → 打开音量合成器，确认浏览器没被静音、输出设备是你正在用的那个。
  3. 看 Chrome 的站点声音：地址栏最左侧的图标 → 权限里「声音」选「允许」；或在标签页上右键，确认没有「静音网站」。
  4. 看上面第 ② 步里日语那行标的是「本地」还是「网络语音」：标「网络语音」说明不用装语音包，但要联网——换 Edge 打开、或检查代理/防火墙，往往就能恢复；标「本地」才是真正装好了语音包。
  5. 确认装了日语语音包：Windows 设置 → 时间和语言 → 语言和区域 → 添加语言「日本語」→ 选项 → 下载「文本转语音」（注意不是「语音识别」，那是给语音输入用的）；macOS：系统设置 → 辅助功能 → 朗读内容 → 系统语音 → 下载「Otoya / Kyoko」。
  6. 换 Edge 或 Chrome 再试。Safari / Firefox 对日语语音的支持差别很大。
  7. 上面第 ② 步里如果 ja-JP 一行都没有，那就是缺语音包，装完重启浏览器再来。
