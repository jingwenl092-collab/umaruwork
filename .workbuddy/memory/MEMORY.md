# 项目记忆 — 日译训练场

## 项目定位
中日翻译/口译「技能训练」网页应用（用户已确认）。练翻译用，不是实时翻译工具。

## 第一版范围（已确认）
- 四页面：首页（方向/难度/场景选择 + 概览）、练习页（核心）、练习报告页、历史记录页
- 六步练习循环：出题 → 语音口译/打字输入 → 确认识别文本 → AI 讲评 → 反馈卡片 → 下一句；满 10 句进报告页
- AI 反馈**不打数字分数**（用户明确要求去掉）：改为「总评 + 做得好 + 可以更好 + 参考译文」的讲评式反馈
- 数据存浏览器本地（localStorage，key `riyi_log_v1`），无账户系统
- UI 风格：薄荷绿护眼色系（--bg #ECF2EA / --accent #47835F），低对比、大留白、圆角

## 技术约定与踩坑
- 已发布上线：appId `wbapp_UKLmxnV7CClwQetku66ood`，代码在 riyi-trainer/，入口 index.html
- 线上分享链接：https://riyi-trainer.app.workbuddy.host/ （静态站点；发布必须与云服务保留域名一致，否则 AI 讲评会因 Origin 不匹配而失败）
- 云端 LLM **必须显式选模型**：取 models.list() 第一个（auto）会落到思考型模型，单次讲评 110 秒。首选 deepseek-v4-flash（约 2 秒），备选 hunyuan-chat；glm 系列慢且会输出 ```json 围栏（解析已兼容）
- 语音识别用浏览器 Web Speech API，语种按方向切换（中→日识别 ja-JP，日→中识别 zh-CN）；不支持的浏览器自动降级打字输入
- 素材库内置 120 组句对，按难度（初/中/高）×场景（日常生活、旅行、商务、校园）分类
- TTS 踩坑：设备缺对应语种语音包时，`speechSynthesis.speak()` 会**静默失败**（不发声也不报错），用户感受就是"点了没反应"。必须自己用 `getVoices()` 检测并给出可见提示（含各系统安装语音包指引），不能只调 speak()
- 改完本地代码**不会自动同步到线上**，需重新发布（会覆盖线上现有内容），且每轮都要用户明确同意
