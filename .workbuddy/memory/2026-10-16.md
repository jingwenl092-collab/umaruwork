## 日译训练场 · 修复「参考译文朗读点了没反应」
- 根因：浏览器 `speechSynthesis` 没有对应语种的语音包时，`synth.speak()` 会被**静默忽略**，既不发声也不报错 → 用户感觉"点了没反应"
- 修复方案（js/app.js 重写 TTS 模块）：
  - `refreshVoices()` + 监听 `voiceschanged`，并加 300ms×10 次兜底轮询（部分浏览器不触发 voiceschanged）
  - `pickVoice(lang)`：精确匹配 lang → 前缀匹配 → null
  - 有语音包但目标语种没有 → 不硬用别的语言念，直接给提示
  - 只在「没找到任何语音」时才用 1.2s 兜底检测，避免正常设备上误报提示
  - `onerror` 也弹出提示；按钮在朗读时显示「▷ 朗读中…」，结束/出错恢复
  - 每次新朗读先 `clearSpeechHint()`；切下一句时清除提示
- 新增 UI：`index.html` 的 `#speechHint`（`.hint-text`，amber 提示条），`css/style.css` 增加 `.hint-text` 样式
- 提示文案含分系统安装语音包指引（Windows / macOS / 手机）
