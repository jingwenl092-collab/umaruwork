  ```
  cred=$(printf "protocol=https\nhost=github.com\n\n" | git credential fill)
  tok=$(printf "%s" "$cred" | grep -i '^password=' | head -1 | cut -d= -f2-)
  curl -s --noproxy '*' -X PATCH \
    -H "Authorization: Bearer $tok" -H "Accept: application/vnd.github+json" \
    https://api.github.com/repos/jingwenl092-collab/umaruwork -d '{"private":false}'
  ```
  验证是否真公开：不带 Authorization 匿名访问 `https://api.github.com/repos/{owner}/{repo}`，看 `"private": false`
