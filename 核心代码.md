# 日译训练场 · 核心代码

> 中日翻译 / 口译技能训练网页应用（静态站点，无构建步骤）。
> 本文归档应用全部源码，便于查阅、分享与备份。

## 一、怎么跑

静态站点，起个本地 HTTP 服务即可：

```bash
cd riyi-trainer
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

注意：**直接双击 `index.html` 用 `file://` 打开时，麦克风（语音识别）在多数浏览器里不可用**，
另外云端 AI 讲评会因 Origin 不匹配而校验失败。要完整体验请用 HTTP 方式访问。

线上版：https://riyi-trainer.app.workbuddy.host/

## 二、目录结构

```
riyi-trainer/
├── index.html                 页面骨架（四个页面区域 + 脚本加载）
├── css/style.css              薄荷绿护眼主题
└── js/
    ├── cloud-config.js        云端服务的公开配置（publishableKey 等）
    ├── data-daily.js          题库：日常生活（60 句）
    ├── data-travel.js         题库：旅行（60 句）
    ├── data-business.js       题库：商务（60 句）
    ├── data-campus.js         题库：校园（60 句）
    ├── data.js                归一化器：把带注音标记的题库整理成可用结构
    ├── app.js                 应用主逻辑（练习循环、语音、比对、AI 讲评、日志）
    └── check-data.js          题库校验脚本（改完题库跑一遍）
```

**脚本加载顺序不能变**：先 4 个题库文件 → 再 `data.js`（归一化器，依赖题库文件）→ 最后 `app.js`（依赖 `window.SENTENCES`）。

## 三、两种训练模式

| 模式 | 说明 |
|---|---|
| 🎧 盲听同传 | 原句高斯模糊遮罩 → 自动朗读 → 读完自动开麦并按难度倒计时（初级 12s / 中级 16s / 高级 20s），可点「显示原句」偷看 |
| 📖 常规看句 | 直接显示原句与振假名，自由口译或打字，无倒计时 |

倒计时归零时：已有作答则自动提交，否则揭晓原句并提示继续作答。

## 四、数据格式：注音标记规范

题库里的日文用 `{汉字|读音}` 标记，`data.js` 会自动派生两份：

- `ja` —— 去掉标记的**纯文本**，给朗读和 AI 讲评用
- `furi` —— 保留标记，给页面渲染成 `<ruby>` 振假名用

写法约束：
1. 竖线 `|` 左边只能放汉字，右边只放假名读音
2. 不要嵌套、不要跨词拆标记
3. 熟词/简单词可以不用标，避免满屏注音影响阅读

## 五、反馈机制：本地比对 + AI 讲评

提交后**两套反馈并存**：

**1. 本地 LCS 字面比对（立即呈现，离线可用）**
基于最长公共子序列算字符级重合度，在「你的翻译」和「参考译文」上用
绿底（命中）/ 红底波浪线（差异）标出，并给出重合度百分比与四档总评。

**2. 云端 AI 讲评（异步补上）**
以资深中日翻译教练的口吻给出「总评 + 做得好 + 可以更好」，**不打数字分数**。
讲评结果并入本轮记录，报告页与历史页可回看。

AI 讲评失败时（无 SDK、网络问题、Origin 校验失败等）只显示一条可重试的提示，
**不影响本地比对结果**——断网也能照常练习。

> 模型选择要点：云端 `models.list()` 返回的第一个是思考型模型，单次讲评约 110 秒。
> 代码里显式优先 `deepseek-v4-flash`（约 2 秒），备选 `hunyuan-chat`。

  function compareTexts(userRaw, refRaw) {

        else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);

        uHit[x - 1] = true;
        rHit[y - 1] = true;

      } else if (dp[x - 1][y] >= dp[x][y - 1]) {
        x--;
      } else {
        y--;
      }

  function doSpeak(text, lang, btn, onDone, hintId) {
    var synth = window.speechSynthesis;
    var u = new SpeechSynthesisUtterance(text);
    u.lang = lang;
    u.rate = 0.95;
    u.pitch = 1;

    var v = pickVoice(lang);
    if (v) u.voice = v;

    if (speechVoices.length && !v) {
      showSpeechHint(lang, hintId);
      if (onDone) onDone();
      return;
    }

    var finished = false;
    function finishOnce() {
      if (finished) return;
      finished = true;
      setSpeakLabel(btn, false);
      if (onDone) onDone();
    }

    u.onstart = function () { setSpeakLabel(btn, true); };
    u.onend = finishOnce;
    u.onerror = function () {
      showSpeechHint(lang, hintId);
      finishOnce();
    };

    try { synth.resume(); } catch (err) {}
    try { synth.speak(u); } catch (err) {
      showSpeechHint(lang, hintId);
      finishOnce();
      return;
    }

    if (!v) {
      setTimeout(function () {
        if (!synth.speaking && !synth.pending) {
          showSpeechHint(lang, hintId);
          finishOnce();
        }
      }, 1200);
    }
  }

  function speak(text, lang, btn, onDone, hintId) {
    if (!('speechSynthesis' in window) || !text) {
      if (onDone) onDone();
      return;
    }
    clearSpeechHint();
    var synth = window.speechSynthesis;
    try {
      if (synth.speaking || synth.pending) {
        synth.cancel();
        setTimeout(function () { doSpeak(text, lang, btn, onDone, hintId); }, 180);
      } else {
        doSpeak(text, lang, btn, onDone, hintId);
      }
    } catch (e) {
      showSpeechHint(lang, hintId);
      if (onDone) onDone();
    }
  }

  if (!s.ja || !s.ja.trim()) errs.push(tag + ' 日文为空');

  // 3. 日文必须含假名
  if (!/[\u3040-\u30ff]/.test(s.ja)) errs.push(tag + ' 日文无假名: ' + s.ja);

  // 4. 注音标记配对检查
  var open = (s.furi.match(/\{/g) || []).length;
  var close = (s.furi.match(/\}/g) || []).length;
  var bar = (s.furi.match(/\|/g) || []).length;
  if (open !== close || open !== bar) errs.push(tag + ' 注音标记不配对 {=' + open + ' }=' + close + ' |=' + bar);

  // 5. 去标记后应等于 ja，且无残留
  var stripped = s.furi.replace(/\{([^{}|]+)\|([^{}]+)\}/g, '$1');
  if (stripped !== s.ja) errs.push(tag + ' 去标记后与 ja 不一致\n    furi→ ' + stripped + '\n    ja  → ' + s.ja);
  if (/[{}|]/.test(stripped)) errs.push(tag + ' 去标记后有残留符号: ' + stripped);

  // 6. 注音里不得含汉字以外的怪东西（读音必须是纯假名）
  s.furi.replace(/\{([^{}|]+)\|([^{}]+)\}/g, function (_, w, r) {
    if (!/^[\u3040-\u30ff]+$/.test(r)) errs.push(tag + ' 读音不是纯假名: {' + w + '|' + r + '}');
    if (!/[\u4e00-\u9fff]/.test(w)) warns.push(tag + ' 注音对象不含汉字: {' + w + '|' + r + '}');
    return '';
  });

  // 7. 重复检查
  if (seenJa[s.ja]) errs.push(tag + ' 日文重复: ' + s.ja + '（与 #' + seenJa[s.ja] + '）');
  else seenJa[s.ja] = i + 1;
  if (seenZh[s.zh]) errs.push(tag + ' 中文重复: ' + s.zh);
  else seenZh[s.zh] = i + 1;

  // 8. 日常生活场景不得出现重敬语（用户反馈的整改项）
  if (s.scene === 'daily' && /させていただ|でござい|ございました|拝受|お伝えください|ご回答/.test(s.ja)) {
    errs.push(tag + ' 日常场景出现重敬语: ' + s.ja);
  }
});

// 9. 每组 20 句
SCENES.forEach(function (sc) {
  [1, 2, 3].forEach(function (lv) {
    var n = count[sc + '/' + lv] || 0;
    if (n !== 20) errs.push('分组 ' + sc + '/L' + lv + ' 句数=' + n + '（应为 20）');
  });
});

console.log('总句数: ' + S.length + (S.length === 240 ? ' ✓' : ' ✗ 应为 240'));
console.log('分组: ' + JSON.stringify(count));
console.log('错误 ' + errs.length + ' 条' + (errs.length ? '：' : ' ✓'));
errs.forEach(function (e) { console.log('  ✗ ' + e); });
console.log('提醒 ' + warns.length + ' 条');
warns.forEach(function (w) { console.log('  ⚠ ' + w); });
process.exit(errs.length ? 1 : 0);

### 语体约定

- **日常生活**：初级=简单敬体，中级=自然口语敬体，高级=真实生活简体口语。
  `させていただく` / `でございます` 这类重敬语**不出现**在日常场景
- **商务**：保留敬语（商务场景本来就该用敬语）
- **旅行 / 校园**：以实际场景常用表达为准
